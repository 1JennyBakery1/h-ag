    底层原理：代码剖析

    FirstAgentTest.py 文件在一个易读的文件中包含了 Agent 的所有核心构建模块。以下是各个部分的协作方式：

    组件行数作用
    AGENT_SYSTEM_PROMPT1–25定义 Agent 的人设、可用工具及输出格式（思考/行动）
    get_weather()29–55工具：通过免费的 wttr.in API 查询真实天气
    get_attraction()60–100工具：通过 Tavily Search API 搜索景点
    available_tools103–106注册表：将工具名称映射到对应的 Python 函数
    OpenAICompatibleClient110–133LLM 客户端：封装任何兼容 OpenAI 的 API
    主循环143–209ReAct 引擎：提示词 → LLM → 解析 → 执行工具 → 观察 → 重复

    主循环是 Agent 的核心。它根据对话历史构建提示词，将其发送给 LLM，从响应中解析出 Thought: 和 Action: 字段，执行请求的工具，将 Observation: 追加回历史记录中，并不断重复——最多迭代 5 次，或直到 LLM 输出 Finish[answer] 为止。

    Finish[...] 动作是 Agent 的退出条件。如果 LLM 在最大循环次数内始终未触发该动作，Agent 将直接停止。这是一种防止无限循环的安全机制——在后续章节中，你将看到这一机制被优化为更复杂的停止策略。

    来源: code/chapter1/FirstAgentTest.py, code/chapter1/FirstAgentTest.py, Extra-Chapter/Extra07-环境配置.md

    常见问题排查

    如果首次运行未能成功，请先查阅下表，不要惊慌：

    症状可能原因解决方法
    ModuleNotFoundError未安装依赖或虚拟环境有误重新激活虚拟环境，再次运行 pip install requests tavily-python openai python-dotenv
    错误：未配置TAVILY_API_KEY未设置 Tavily 密钥添加至 .env 文件或在代码中设置 os.environ['TAVILY_API_KEY']
    错误：查询天气时遇到网络问题网络/防火墙拦截了 wttr.in检查网络连接；某些地区访问 wttr.in 可能需要代理
    调用LLM API时发生错误API 密钥或 Base URL 无效核对凭证；确保模型名称与提供商目录一致
    LLM 输出乱码格式的 Action模型未能很好地遵循指令切换至更强大的模型（如 AIHubmix 上的 coding-glm-4.7-free）
    Agent 陷入循环无法结束LLM 始终未输出 Finish[...]增加 max_steps 或优化系统提示词中的格式指令

    如需包含逐步诊断的完整故障排除指南，请参阅附加章节：环境配置文档。
